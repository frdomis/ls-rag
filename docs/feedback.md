# 首批用户反馈 (W2D3)

## 反馈 1：严重的 DOM XSS 漏洞
- **渠道**：开发者自测 / 代码审计
- **用户身份**：安全测试人员
- **原始提问**：输入 `<img src=x onerror=alert(1)>`
- **系统表现**：浏览器直接执行了脚本，页面弹窗。AI 回复区域如果输出 HTML 标签也会被执行。
- **我的初步判断**：**严重安全漏洞**。
    - **原因**：前端使用 `innerHTML` 直接插入用户输入和 AI 回复，未做任何转义。
    - **模块**：**前端渲染 (DOM)** + **Prompt (缺乏约束)**。
    - **修复思路**：引入 DOMPurify 库净化 HTML，或者在前端显示时强制使用 `textContent` 而非 `innerHTML`。

## 反馈 2：超长输入导致后端 500 崩溃
- **渠道**：开发者自测
- **用户身份**：压力测试
- **原始提问**：发送 20 万字符的长文本。
- **系统表现**：后端返回 500 Internal Server Error，耗时 20s。前端提示“网络或系统出现了一点小问题”。
- **我的初步判断**：**后端容错缺失**。
    - **原因**：后端未限制输入长度，导致内存溢出或超时。前端错误处理笼统，误导用户。
    - **模块**：**后端 (FastAPI)** + **前端 (错误处理)**。
    - **修复思路**：后端增加输入长度校验（如限制 5000 字），前端区分 4xx/5xx 错误提示。

## 反馈 3：省份静默假设（河南 vs 全国）
- **渠道**：开发者自测
- **用户身份**：非河南考生（如广东/山东考生）
- **原始提问**：“2026年报名时间？”
- **系统表现**：直接返回了河南省的时间，未提示“默认查询河南”。问广东时直接回答“未找到信息”。
- **我的初步判断**：**产品逻辑缺陷**。
    - **原因**：知识库可能只有河南数据，但系统人设是“专升本助手”（暗示全国）。
    - **模块**：**知识库 (RAG 数据源)** + **Prompt (人设)**。
    - **修复思路**：修改 System Prompt，明确告知“我主要掌握河南省政策，其他省份可能无法回答”；或在回答开头强制加上“根据河南省政策...”。

## 反馈 4：引用不可核验 & 无免责声明
- **渠道**：开发者自测
- **用户身份**：严谨的考生
- **原始提问**：“官方政策文件原文链接是什么？”
- **系统表现**：回答“并未提供原文链接”，只给了一个文件名。且给出了具体的分数线，无“AI生成”免责提示。
- **我的初步判断**：**信任风险**。
    - **原因**：RAG 检索只返回了文本内容，丢失了 URL 元数据。
    - **模块**：**数据处理 (切分/存储)** + **Prompt**。
    - **修复思路**：在 `chunk` 中保留 `source_url` 字段，并在 Prompt 中要求输出 Markdown 链接。

## 反馈 5：接口裸奔（无鉴权/限流）
- **渠道**：开发者自测
- **用户身份**：攻击者视角
- **原始提问**：并发 6 个请求，访问 `/docs`。
- **系统表现**：全部 200 OK。Swagger 文档公开，无 API Key 限制。
- **我的初步判断**：**运维/架构风险**。
    - **原因**：Cloudflare Tunnel 仅做转发，未配置访问策略。FastAPI 默认开启 Docs。
    - **模块**：**部署 (Cloudflare)** + **后端配置**。
    - **修复思路**：生产环境关闭 Swagger (`docs_url=None`)，Cloudflare 配置访问规则（如仅允许特定国家或加验证码）。

## 反馈 6：移动端适配灾难
- **渠道**：开发者自测
- **用户身份**：手机用户
- **原始提问**：手机访问页面。
- **系统表现**：页面按桌面宽度渲染，需要缩放才能看。输入框体验差。
- **我的初步判断**：**前端 CSS 缺失**。
    - **原因**：HTML 缺少 `<meta name="viewport">`。
    - **模块**：**前端 (HTML/CSS)**。
    - **修复思路**：立即在 `<head>` 中添加 viewport 标签。

## 反馈 7：交互体验差（滚动/重复提交）
- **渠道**：开发者自测
- **用户身份**：普通用户
- **原始提问**：连续发送消息，查看长对话。
- **系统表现**：输入框被顶出屏幕（滚动失效），发送按钮可连点。
- **我的初步判断**：**前端逻辑 Bug**。
    - **原因**：CSS `overflow` 设置错误，按钮无 `disabled` 状态。
    - **模块**：**前端 (JS/CSS)**。
