# W5D3 rerank 对比

- rerank 模型：`BAAI/bge-reranker-v2-m3`
- 分母：33

| 配置 | recall@5 |
|---|---|
| 向量不过滤 top5（线上基线） | 19/33 = 57.6% |     A
| 向量过滤 top5（W5D2 最优） | 24/33 = 72.7% |       B
| 过滤 + BM25/向量 并集top20 → rerank | 26/33 = 78.8% |    C
| 不过滤 +  BM25/向量 并集top20 → rerank | 21/33 = 63.6% |       D
结果	结论
C (26/33)> B（24/33）	rerank 有效，把候选里排不进 top5 的答案重排上来了
C = B	过滤后候选太小（policy 才 10 块），rerank 没有优化空间
C < B	rerank 判断和标注不一致，值得深挖（可能是标注质量问题）

候选内含答案=False 的题	rerank 救不了，属于召回失败 → 要靠 query 改写（W5D5）或补语料
- rerank 延迟 P50=1289ms / P95=2601ms
- 平均候选 15.0 条
