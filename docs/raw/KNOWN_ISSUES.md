# 已知缺陷清单

> 本文件记录当前未解决的问题，按优先级排序。

## 1. 要点覆盖率偏低（38.3%）

- **现象**：128 个期望要点仅覆盖 49 个，覆盖率 38.3%
- **归因**：79/79 条为 `miss_recall`，检索层未召回正确答案
- **原因假设**：chunk=200 粒度过大，关键信息被切散；无重排序，Top-5 精度不足
- **下一步**：① 加 Cross-Encoder 重排；② 调整 chunk 切分策略；③ 补充缺失文档

## 2. 口语化提问召回偏低

- **现象**：口语化题目（如"我能跨专业考汉语言吗"）在 BM25 路召回效果差
- **原因假设**：口语表达与政策文档书面语词汇重叠少，BM25 关键词匹配失效
- **下一步**：引入 query 改写 / 同义词扩展，或提高向量路权重

## 3. 跨文档多跳问题答不好

- **现象**：答案分散在多个文档时，单路检索难以拼凑完整信息
- **原因假设**：当前检索为单轮 Top-K，无多跳推理能力
- **下一步**：暂不处理，待单跳覆盖率达标后再考虑

## 4. BM25 在特定题型上优于向量

- **现象**：精确时间/数字类问题（如"报名截止时间"）BM25 表现更稳
- **原因假设**：向量检索对专有名词/数字的语义相似度计算不够敏感
- **下一步**：保持混合检索，利用两者互补性

## 5. 拒答题型未做专门处理

- **现象**：5 题标注为"超出覆盖范围"，当前仍会强行检索并生成答案
- **原因假设**：缺少拒答分类器 / 置信度阈值
- **下一步**：增加意图识别层，对超出范围的提问走拒答话术
