# 项目定位

## 一句话定位

面向河南省专升本考生的 RAG 智能问答系统，帮助考生从繁杂的政策文件中快速检索到准确的报名、考试、录取等信息。

## 系统是什么

基于 RAG（检索增强生成）技术的专升本政策问答助手。用户上传专升本政策 PDF 文件，系统自动完成文本分块、向量化并存入 Qdrant 向量数据库；考生提问时，系统先检索最相关的政策原文，再交给 DeepSeek 大模型生成准确回答，附带原文来源，避免大模型"编造"答案。

## 服务谁

河南省普通专升本考生（在校专科生），以及对专升本政策有疑问的考生家长。

## 解决什么问题

- **政策文件多、查找难**：河南省专升本涉及报名、考试、志愿填报、录取等多个环节，相关文件散落在不同 PDF 中，手动翻阅效率低。
- **通用 AI 回答不准**：直接用 ChatGPT/文心一言问专升本政策，容易得到过时或张冠李戴的答案，因为大模型并不了解具体省份的具体政策。
- **信息时效性强**：每年的报名时间、考试科目都可能调整，考生需要一个能跟随最新文件更新的问答工具。

本系统通过"先检索原文、再生成回答"的 RAG 机制，确保回答有据可查、来源可溯，解决通用大模型在垂直政策领域的"幻觉"问题。
